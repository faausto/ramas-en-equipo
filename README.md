# **Ramas en Equipo — Git y GitHub**

## Descripción
Repositorio de práctica realizado en parejas para la materia Software Factory II.
El proyecto está orientado al trabajo colaborativo utilizando ramas en Git, merges y resolución de conflictos en GitHub.

## Contenido
- `saludo.py` — Script que muestra un saludo por consola
- `despedida.py` — Script que muestra un mensaje de despedida
- `equipo.py` — Script relacionado con la información del equipo de trabajo

## Cómo ejecutar

**Requisito: tener Python 3 instalado.**

Todos los archivos `.py` de este repositorio son independientes y pueden ejecutarse desde la terminal.

### En Windows
```bash
python nombre_del_archivo.py
```
o también:
```bash
py nombre_del_archivo.py
```

**Ejemplos:**
```bash
python saludo.py
py equipo.py
```

### En Linux o MacOS
```bash
python3 nombre_del_archivo.py
```

**Ejemplo:**
```bash
python3 despedida.py
```

## Objetivos del ejercicio
- Practicar el uso de ramas en Git
- Realizar merges entre ramas
- Resolver conflictos de manera colaborativa
- Trabajar en equipo utilizando GitHub

## Tecnologías
- Git
- GitHub
- Python 3
